# 本地网页演示

当前是规则路由与批准 SQL 驱动的单用户原型，未接入大模型。

先安装 requirements.txt 的依赖，并运行 18_sql_metric_foundation.py 准备本地数据库，再在项目根目录执行：

```powershell
python -m streamlit run app.py --server.address 127.0.0.1
```

打开终端显示的本地地址。选择示例或输入问题，点击查询；页面展示结果、口径、SQL 依据，支持完整结果 CSV 下载。修改问题但未点击查询时，保留的结果明确显示对应旧问题。

验收：全体排名返回 26–35 岁男性第一；26–35 岁女性占全体约 8.69%、占该年龄段约 21.80%；20–30 岁请求澄清；日期问题说明不支持。数据库不存在时显示准备提示。

关闭浏览器不会停止服务；在启动服务的终端按 Ctrl+C 停止。数据库和原始数据不上传 GitHub。
