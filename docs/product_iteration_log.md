# 产品迭代记录

## 2026-10-12：规则版问答首次试用

实际试用覆盖客群贡献查询、指标解释和不支持的日期问题，三个路径均按预期返回。

发现：完整英文 JSON 占用大量终端空间，结论和证据难以快速阅读。

调整：保留首句结论，默认展示中文前五名客群，格式化人数、金额和百分比；完整结果导出为中文表头 CSV，保留查询来源、数据范围和指标口径。CSV 保留数值，占比为 0–1 小数。

验证：重跑固定规则验收用例，并实际运行查询检查输出与 CSV。规则测试不是独立 AI 准确率评测；改版可用性仍需后续用户试用验证。

当前为单用户本地规则原型，未接入大模型、未实施企业权限控制，也未进行客户部署。
