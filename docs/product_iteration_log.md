# 产品迭代记录

## 2026-10-26：受控 RAG 知识问答与证据链（本地验证）

目标：将指标定义、数据限制和产品说明从 SQL 数值查询中分离，补充可检索、可引用、可拒答的知识问答路径。

新增：完整 PRD、4份批准知识文档共30个章节、中文关键词检索基线、DeepSeek受控生成、引用ID白名单、无依据调用前拒答、证据JSON导出，以及独立的Streamlit RAG展示区。结构化经营数值仍由参数化SQL计算，RAG不检索交易明细。

验证：关键词检索可见开发集12/12。真实模型v1人工复核11/12；R10虽然数字正确，但遗漏“不能当作账号总消费”的限制。保留失败后增加通用范围约束形成v2，R10定向回归两次通过。R04记录了自动评分同义词假阴性，R06保留首次模型错误；一次Excel文件锁导致批次未保存，评测器随后改为逐题唯一归档。

限制：开发题可见且参与了迭代，不是外部独立评测；没有真实企业知识库或生产流量。公开版只提供规则SQL查询与免费知识检索，付费模型入口仍需鉴权、持久化配额和费用控制。

## 2026-10-16：多指标分析与简报导出（本地待发布）

目标：从单一取数扩展到“选目标—比较客群—核查口径—导出简报”的完整分析流程。

新增：全体14个客群的消费贡献、人均累计消费、用户规模和人均购买记录数比较，前六名指标图、完整对比表与规则生成的 Markdown 简报。独立注明该模块使用全体客群，不受上方单客群筛选影响。

体验调整：长金额卡片使用万/亿数量缩写，悬浮帮助、明细和导出保留完整值；查询状态改为中文。简报区分观察结果与待验证运营建议，不输出虚构增量或最优预算。

限制：没有新增模型能力；简报为固定规则生成。改版尚待真实用户可用性验证，不能据页面测试推断业务效果。

## 2026-10-12：规则版问答首次试用

实际试用覆盖客群贡献查询、指标解释和不支持的日期问题，三个路径均按预期返回。

发现：完整英文 JSON 占用大量终端空间，结论和证据难以快速阅读。

调整：保留首句结论，默认展示中文前五名客群，格式化人数、金额和百分比；完整结果导出为中文表头 CSV，保留查询来源、数据范围和指标口径。CSV 保留数值，占比为 0–1 小数。

验证：重跑固定规则验收用例，并实际运行查询检查输出与 CSV。规则测试不是独立 AI 准确率评测；改版可用性仍需后续用户试用验证。

当前为单用户本地规则原型，未接入大模型、未实施企业权限控制，也未进行客户部署。
